# Research_Documents — what this folder is

```pseudocode
THIS_FOLDER: input for coding agents and for later research sessions
NOT: designer notes
NOT: automatically canonical
NOT: a licence to invent the game's design, rewrite the README as a PRD, or start coding systems as if these files were specs
```

James's standing rule from Teutoburg (2026-09-10): findings from historical or comparative investigation should live in a findable document so other sessions can use them, without being treated as automatically canonical. Designer notes are James-only. Do not name anything in this folder a designer note.

Hispania's only existing canon on `master` as of 2026-09-18 is the two-line README:

> RPG game set in Iron Age Spain, where the player starts as a Celtiberian tribesman who must side with the Romans, Carthaginians, or Iberians

Everything below that line is still unwritten. These files do not fill that gap. They give later sessions something to argue from.

## Claim tags

Every historical or comparative claim should carry one of:

- `[FACT - cited]` — a specific source, with a working link or a primary-text locus
- `[INFERENCE]` — a step beyond the source, argued
- `[SPECULATION]` — useful, not sourced enough to lean on
- `[GAP FLAGGED]` — the evidence runs out; stop inventing
